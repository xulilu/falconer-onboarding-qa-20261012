# Nimbus QA API reference

This reference describes the current Nimbus QA v2 service as of 2026-10-12.
All organizations use these settings.

Access tokens expire after 60 minutes.
An organization can create a maximum of 50 API keys.
API pagination returns 200 records per page by default.
The API authenticates requests with the X-Nimbus-Key header.
Per-organization request limits are 500 requests per minute.
Export jobs produce CSV files.

The API documentation applies to the same Nimbus QA v2 organizations described in the overview.
No enterprise or legacy plan exceptions exist.
